# 📘 Mini Compiler (Java + ANTLR4)

A simple Mini Compiler project that implements major compiler phases for a C-like language using Java and ANTLR4.

---

## 🚀 Features

- Lexical Analysis (Token generation)  
- Syntax Analysis (Parse Tree)  
- Semantic Analysis  
- Symbol Table  
- Abstract Syntax Tree (AST)  
- Three Address Code (TAC)  
- Quadruples & Triples  
- Type Checking  
- Dead Code Elimination  
- Optimized TAC  
- Colored Console Output  

---

## 🧠 Compiler Flow

Source Code → Lexer → Parser → AST → Semantic → TAC → Optimization

---

## 📥 Sample Input

```c
int a = 10;
int b = 20;
c = a + b;
print(c);
⚙️ How to Run
javac -cp ".;lib/antlr-4.13.2-complete.jar" src/*.java generated/*.java
java -cp ".;lib/antlr-4.13.2-complete.jar;src;generated" Main
